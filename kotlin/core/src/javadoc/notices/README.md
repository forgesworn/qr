# Javadoc third-party notices

The Maven Javadoc JAR contains Kotlin API documentation in the standard HTML
format from [Dokka 2.2.0](https://github.com/Kotlin/dokka/tree/v2.2.0).
`DOKKA-LICENSE.txt` and `DOKKA-NOTICE.txt` come from that tag.
`DOKKA-HTML-LICENSES.txt` contains the licence texts for the third-party code
and fonts in the generated HTML assets.

The JavaScript and CSS bundles were reproduced from the tag's
[frontend lockfile](https://github.com/Kotlin/dokka/blob/v2.2.0/dokka-subprojects/plugin-base-frontend/package-lock.json).
The source maps identify the npm packages present in those bundles. The font
files match the corresponding Fontsource packages. The Inter and JetBrains
Mono notices also include the copyright holders named in the font metadata.
